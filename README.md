# tw4 Homebrew tap

```bash
brew trust tw4/tap   # Homebrew 7+ asks you to trust third-party taps once
brew install --cask tw4/tap/lumela
```

| Cask | |
|---|---|
| [lumela](Casks/lumela.rb) | [Lumela](https://github.com/tw4/lumela): capture, beautify, annotate, redact and copy text from screenshots |
